# História de Campina Grande | PROJETO DE CONCLUSÃO DE CURSO

Um web site mostrando a história da cidade paraibana de Campina Grande.

Campina Grande já foi aldeia de índios Cariris, se torno vila com nome de Vila Nova da Rainha, mas foi aproximadamente 70 anos depois que tornou-se cidade.

Já parou para pensar como era a rua em que você anda todo dia a centenas de anos atrás?
